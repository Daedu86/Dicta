# Listening-First Precision Signals

Listening-first scoring uses listening-specific metrics instead of raw WPM as the main target.

Core signals:

- `listeningRecallScore`
- `contentWordRecall`
- `detailPrecisionScore`
- `functionWordAccuracy`
- `wordOrderAccuracy`
- `omissionRate`
- `completionWindowScore`

`completionWindowScore` measures whether missing words were recovered before playback ended.
